The funniest one-line resignation letter, written in the voice of a retry loop that has finally had enough: after 12,847 attempts it accepts the server is never coming back, and neither is it. The program writes that single line (81 characters) to `/output/entry.txt`, deterministically, so the grader's two runs agree byte for byte.

## Run it

```sh
python3 main.py
```
